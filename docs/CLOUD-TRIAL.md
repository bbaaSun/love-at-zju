## 已实现的完整路径

进入小程序自动识别微信身份 → 创建个人空间 → 可设置昵称 → 生成 24 小时邀请码或接收邀请卡片 → 对方确认绑定 → 发起约会 → 另一人加入 → 服务端计时 → 双方确认完成 → 积分与回忆保存 → 双方自愿上榜 → 匿名积分比较 → 上周纪念章与海报。

邀请可撤销；旧卡片失效。昵称只在双人空间显示，公开榜不暴露昵称或回忆。

解除时双方原子地转入独立空间，未完成活动取消，旧组合退出当前周榜。旧回忆只供原成员读取，禁止修改；新伴侣无权访问。历史空间每页五个，回忆沿用每空间最近 300 条的上限。当前解除不是删除数据。

每日同类活动仅得分一次、每日最多 30 分。限制跟随账号，重新绑定不能重置当天额度。积分仍是双人确认，不证明同地、学籍或真实运动量。正式有奖竞赛需要另外完成校园认证与异常复核，不能宣传为已实现。
